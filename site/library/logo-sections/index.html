A logo row is borrowed credibility: it only works if the visitor recognises the names.

How to choose logos & partners

Six logos nobody knows persuade less than two that everyone does. The layout matters less than the choice, but the wrong layout can bury good names — too small, too many, or moving too fast to read.

A strip under the hero — when you have four to six recognisable clients. One quiet line — “Trusted by” — and the logos at equal optical size, greyed so none shouts.

A grid with a sentence — for partners, certifications or stockists, where the relationship needs explaining. The sentence says what the logos have in common.

A carousel — only for long lists, and slow enough to read. If a visitor has to wait for a name to come round, it is not doing its job.

What is inside the block

A Rumouz block is a container holding image widgets (or Elementor’s free image carousel) in a row or grid, usually with a short heading. Swap each placeholder for an SVG or transparent PNG; keep them the same height and the grid stays even.

Import into Elementor

  1. Download the block (or your whole stacked page) from the Studio as a .json file.
  2. In WordPress go to Templates → Saved Templates and click Import Templates.
  3. Choose the file. It appears under Saved Templates with its ASAS name.
  4. Open any page in Elementor, click the folder icon, choose My Templates, and insert it.

Questions

Logos & partners, answered.

What size should the logos be?

Aim for the same visual weight rather than the same width: wide wordmarks shorter, square marks taller. Upload SVG or transparent PNG so they sit on any kit colour.

Can the logos be grey and turn colour on hover?

Yes. Apply a CSS filter to the image widget in Elementor (Style → CSS Filters: grayscale) and remove it on hover. It needs no add-on.

Are these templates free?

Yes. Browsing, stacking and colouring need no account. Downloading the Elementor JSON needs a free account — a name, an email and a password, no card.

Do I need Elementor Pro?

Most blocks use core Elementor widgets only. Where a block uses a Pro widget, the Studio names it before you download, because Elementor silently drops widgets it doesn’t have on import.

How do I import a block into Elementor?

Download the .json file, open Templates → Saved Templates in WordPress, click Import Templates, choose the file, then insert it on any page from the editor’s template library.
